# Image Processing, Computer Vision & Visualization

A Python practice repository covering image visualization, interactive plotting, OpenCV-based image processing, and YOLO-oriented object-detection exercises.

## Structure
- `Matplotlib/matplotlib (1).py` — Matplotlib practice.
- `Open Cv/` — OpenCV programs including `open_cv.py` and `fd1.py`–`fd6.py`.
- `Plotly/plotly.ipynb` — interactive Plotly notebook.
- `YOLO/y01.py`–`y12.py` — YOLO-related exercises.

## Technologies
Python, NumPy, Matplotlib, Plotly, OpenCV, YOLO/Ultralytics tooling, and Jupyter Notebook.

## Installation
The existing project documentation identifies: `pip install numpy matplotlib plotly opencv-python ultralytics`

Individual exercises may require additional packages or local input/model files.

## Running
Example: `python "Open Cv/open_cv.py"`

YOLO example: `python YOLO/y01.py`

Review each script before running it because exercises may expect images, videos, webcam access, or model files.

## Learning Path
Python/NumPy → Matplotlib/Plotly → image processing → OpenCV → computer vision → YOLO/object detection.

## Notes
This is a collection of practical exercises rather than a single packaged application. No unsupported accuracy or performance metrics are claimed.
